# 双呈现模式与后续行动建议

剧本包在 `manifest.json` 中设置 `presentation_mode`，取值为 `interactive` 或 `novel`；未设置的旧剧本保持交互模式。该字段只控制玩家看到的正文，与目录中的 `campaign` / `freeform` 流程类型相互独立。

两种模式共享主控 ReAct、NPC 独立上下文、事件提交、可见性过滤、时间与存档。交互模式按事件顺序呈现角色回应与场景承接。小说模式在同一轮的所有可见结果提交后，由主控侧的呈现器生成一段玩家第一人称正文。正文单独保存以支持重试；它不产生世界效果，也不写入 NPC 或玩家的权威观察。流式进度仍报告执行阶段，但小说模式在整合前不向玩家展示原始 NPC 片段。

普通回合的最终正文完成后，独立的轻量模型只读取玩家可见文本，生成三个不同的后续行动，包含按钮标题与可直接提交的玩家输入。选项不是剧情事实，也不限制自由输入。模型失败或超过短超时时使用安全的通用建议；已提交的故事结果不因此回滚。剧情必选节点沿用剧本定义的合法选项，不生成绕过节点的自由行动。完整结局不再推荐行动。

玩家积分按实际成功的模型 Token 调用结算。推荐行动使用单独的可配置模型任务；创建存档时的开场建议由平台承担。Langfuse 将正文呈现和推荐调用关联到游戏 session。剧本作者负责为小说模式编写第一人称开场文案。
