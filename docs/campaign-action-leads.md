# 剧情场景的行动线索

固定剧本可以在 `campaign.json` 的 `scene` 步骤中声明玩家此刻看得见的主线目标和行动线索。主控仍处理玩家自由输入；这些字段只影响回合结束后的三条推荐行动，不构成固定动作列表。

```json
{
  "id": "first_evening",
  "at": 0,
  "kind": "scene",
  "text": "晚餐桌边，几位嘉宾正在商量今晚的安排。",
  "action_goal": "认识一位嘉宾，并了解今晚的共同环节。",
  "action_anchors": ["晚餐", "嘉宾", "节目组"],
  "action_leads": [
    {"label": "加入晚餐准备", "input": "我走到晚餐桌边，问大家有什么需要帮忙。"},
    {"label": "认识一位嘉宾", "input": "我向身旁的嘉宾介绍自己，问他为什么来到这里。"},
    {"label": "问今晚的安排", "input": "我问节目组今晚有哪些共同环节。"}
  ]
}
```

三个字段均可省略。运行时只读取已经进入玩家视野的最近一个场景，不把未来步骤送给推荐模型。推荐模型同时得到本轮故事正文、当前目标、场景线索和最近的玩家行动；输出若未触及任何 `action_anchors`，则采用剧本提供的三条 `action_leads`。选项点击后作为普通玩家输入进入 ReAct 回合，由主控和世界状态决定结果与时间流逝。剧情选择关卡仍由 `choice` 步骤处理，不显示普通行动推荐。

修改已发布剧本时应创建新版本并在目录中保留旧包，避免改变已有存档的剧本指纹。
